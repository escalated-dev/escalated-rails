<h1 align="center">Escalated for Rails</h1>

<p align="center">
  أضف مكتب دعم متكاملًا إلى تطبيق Rails الخاص بك.<br>
  تذاكر واتفاقيات مستوى الخدمة (SLA) وقواعد تصعيد وصندوق وارد للوكلاء وبوابة للعملاء، تعمل على قاعدة بياناتك الخاصة.
</p>

## الميزات

<table>
<tr>
<td width="33%" valign="top">

**التذاكر وصندوق الوارد**
- دورة حياة كاملة مع انتقالات الحالة
- مرشحات قوائم الانتظار والإجراءات الجماعية
- ملاحظات داخلية وردود جاهزة
- فصل رد إلى تذكرة جديدة
- تأجيل مع إعدادات مسبقة واستئناف تلقائي
- عروض محفوظة وقوائم انتظار مشتركة

</td>
<td width="33%" valign="top">

**SLA والتصعيد**
- أهداف استجابة وحل لكل أولوية
- ساعات العمل واكتشاف حالات الخرق
- قواعد تصعّد أو تعيد الإسناد أو ترسل إشعارات
- توجيه حسب القسم بالتناوب (round-robin)

</td>
<td width="33%" valign="top">

**العملاء**
- بوابة خدمة ذاتية للعملاء
- تذاكر الضيوف مع وصول عبر رابط سحري
- أداة قابلة للتضمين مع بحث في قاعدة المعرفة
- قاعدة معرفة عامة يمكنك إيقافها

</td>
</tr>
<tr>
<td width="33%" valign="top">

**البريد الإلكتروني**
- استقبال عبر Mailgun أو Postmark أو SES أو IMAP
- ردود مجمّعة في سلاسل داخل برامج البريد
- قوالب بريد تحمل علامتك التجارية
- إشعارات وwebhooks لكل حدث

</td>
<td width="33%" valign="top">

**الإدارة والوصول**
- الأقسام وSLA والقواعد والوسوم والتقارير
- تضمين اختياري في لوحة الإدارة الخاصة بك
- الأدوار والصلاحيات كخيار عند التثبيت
- سجل نشاط زمني على كل تذكرة

</td>
<td width="33%" valign="top">

**ما وراء الكواليس**
- واجهة مشتركة مبنية بـ Vue 3 وInertia.js
- رفع ملفات مع إعدادات التخزين وحدود الحجم
- وسوم ملوّنة لفرز التذاكر
- تحديثات فورية عبر ActionCable مع الاستطلاع (polling) كبديل

</td>
</tr>
</table>

## البدء السريع

```bash
bundle add escalated
npm install @escalated-dev/escalated
rails generate escalated:install
rails db:migrate
```

بعد ذلك افتح `/support`. يتطلب Ruby 3.1+ وRails 7.1+. يشرح [دليل البدء](../getting-started.md) الـ concern المسمى `Ticketable` وفحوصات الوصول.
